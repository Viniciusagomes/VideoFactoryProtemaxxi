# Video Factory Protemaxxi

Fábrica de vídeos 2D da Protemaxxi (personagens, roteiros, vozes ElevenLabs).

## Regras
- Responder sempre em português.
- Tudo em 2D. Os personagens saem de `ferramentas/gerar_personagens.py`: altere o gerador, não o SVG à mão.
- Repositório público: nada de chave de API, dados de clientes ou números de telefone. Chaves só no `.env`.
- Trabalho do Claude em branch `claude/...` + PR; o Vinícius faz o merge.
